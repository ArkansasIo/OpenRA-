Build from source

The repository contains the engine, launcher, server, mod code, and game content definitions. Install the .NET 10 SDK and follow the platform-specific instructions in INSTALL.md.

  • Windows: build with the documented environment, then run launch-game.cmd.
  • Linux: run make, then ./launch-game.sh.
  • macOS: install .NET 10, run make, then ./launch-game.sh.

Distributed mods include Tiberian Dawn, Red Alert, and Dune 2000. Some original game assets may need to be supplied or downloaded separately according to the install guide.

About browser play

GitHub Pages hosts this project page and its links; it does not run the native OpenRA game inside the browser. A genuine browser-playable edition would require a separate port or compatible runtime, plus testing for rendering, input, audio, networking, and mod asset loading.
