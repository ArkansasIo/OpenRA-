OpenRA

Build bases, command armies, and play classic-inspired RTS games with community mods, custom maps, and multiplayer.

Get the full game

OpenRA is a native desktop game. Choose a published installer/package if one is available, or build the complete game from this repository. The download page lists releases and their attached files.

Build from source

The repository includes the game engine, launcher, server, official mod code, and game content definitions. Install the .NET 10 SDK and follow the platform-specific instructions in INSTALL.md.

  • Windows: run launch-game.cmd after building.
  • Linux: run make, then ./launch-game.sh.
  • macOS: install .NET 10, run make, then ./launch-game.sh.

Available game mods include Tiberian Dawn, Red Alert, and Dune 2000; other mods may be experimental. Some original game assets may need to be supplied or downloaded separately according to the install guide.
